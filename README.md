# 通勤時刻表

## 起動
```
pip install -r requirements.txt
streamlit run app.py
```

## フォルダ構成
```
app.py               Streamlit本体
timetable.html       画面（スワイプ・地点タップ・残り時間）
timetable_loader.py  時刻表の読み込みとチェック
data/
  timetable.xlsx     時刻表のExcel（シートごとに1つの時刻表）
  timetables.csv     方向・目標・ファイル・シート・締切
  colors.csv         種別・系統の色
```

## ダイヤ改正のときの手順
1. いつも通りExcelで時刻表を直して保存する（数式もそのまま使えます）
2. `data/timetable.xlsx` と差し替えて GitHub に上げる → Streamlit Cloud に反映

アプリはExcelのシートを直接読みます。
- 数式のセルは、Excelが保存した計算結果を読みます。Excel以外のアプリで保存すると結果が残らないことがあり、
  その場合は「数式の計算結果がありません。Excelで開いて保存し直してください」と表示されます。
- 結合セル（複数のスジが同じ列車・バスに乗る区間）は自動で各列に展開し、「合流」の帯でつなぎます。
- 書き方に誤りがあると、「timetable.xlsx「平日１限」5行目 L列: 時刻「7;05」を読めません」のように
  場所つきで表示されます。

## シートの書き方（今のExcelのままでOK）
- A列＝地点名、B列＝「発」「着」、C列以降＝スジ。最初の行（タイトル）は見出しとして読み飛ばします。
- B列が「発」「着」以外の行は駅と駅の間（区間）の行です。「↓特」「↓K」の矢印は自動で取り除き、
  種別・系統として表示します。「↓」だけなら単なる移動です。
- 地点名が空欄の行は、すぐ上の地点の続きとみなします（A列の結合セル）。
- 接続がないところは空欄か「-」。
- 最後の行の「着」（学校着）が、締切との比較に使われます。
- 新しい種別・系統を使うときは colors.csv に色を足します（書いていないものはグレー）。
- CSVファイル（同じ並び）でも読み込めます。その場合「〃」で左のセルと同じ値にできます。

## timetables.csv
| 方向 | 目標 | ファイル | シート | 締切（学校着） |
|---|---|---|---|---|
| 往路 | 1限 | timetable.xlsx | 平日１限 | 8:50 |
| 往路 | 2限 | timetable.xlsx | 平日２限 | 9:50 |
| 往路 | 3限 | timetable.xlsx | 平日３限 | 10:50 |

- **同じ「方向」のシートは、自宅を出る時刻順に1本の時刻表にまとめます。**
  - 時刻がすべて同じスジは1本に、途中までしか書いていないスジは同じ内容で最後まで書いたスジがあれば除きます。
  - バスの選び方だけ違うスジなどは両方残します。
  - まとめるシートは、地点の並びが同じである必要があります。
- 「目標」は画面上部のボタンになり、選んだ目標の締切で「最終」「遅刻」の印が付きます。
- 方向が2つ以上あると、上部に方向の切り替えが出ます（復路を足すときは「復路」の行を追加）。
- 時刻が前の地点より早くなっているスジがあると、画面上部に「時刻表データの確認」として表示されます。

## colors.csv
種別・系統ごとの色です（`特,#d93025` のように指定）。書いていないものはグレーになります。

## 操作
- 起動時：その時点の時刻で、選択中の地点（最初は自宅）から次のスジを中央に表示
- 目標（1限/2限/3限）の切り替え：印が変わるだけで、表示位置は動かない
- 合流区間：同じ便に乗るスジは横長の帯にまとめ、時刻は帯の右端（画面からはみ出すときは画面の右端）に表示
- 地点名タップ：その地点の「発」（なければ「着」）が現在時刻以降の最初のスジを中央へ。合流区間の中なら、まとまりの最後のスジを中央へ
- 左右スワイプ／◀▶／下の目盛りタップ：スジを移動（時間経過で勝手に動くことはない）
- 残り時間：中央のスジの、選択中の地点の時刻までの残りを10秒ごとに更新（数字だけで、表示位置は動かない）
- テスト時刻：入力するとその時刻を「現在時刻」として扱う（確認用）
- 最後に選んだ目標は次回起動時も選ばれた状態になります
